**Nova Video Translate** — расширение для Chrome (и скрипт для Tampermonkey), которое озвучивает видео на русском языке прямо во время просмотра. Оригинальная дорожка приглушается, закадровый голос идёт поверх. Работает на YouTube и на других сайтах с обычным `<video>`.

## Основные возможности

- **Голоса Яндекса**: «живые» голоса (нужен вход в аккаунт Яндекса) и обычные (без входа). Для готовых переводов Яндекса озвучка начинается сразу.
- **Встроенная нейросеть Chrome**: распознавание речи и перевод на устройстве, без ключей и без отправки звука в облако. Модели скачиваются кнопкой в настройках.
- **Groq (запасной вариант)**: быстрое распознавание речи по вашему бесплатному ключу. Ключ вставляется прямо в настройках, рядом со списком источников.
- **Локальные голоса**: несколько движков, работающих в браузере (WebGPU и CPU). Модели скачиваются один раз и только по вашему клику.
- **Порядок источников настраивается**: перевод берётся у первого включённого источника, при сбое — у следующего.
- **Субтитры**: русские субтитры поверх плеера (по желанию).
- **Умное приглушение**: оригинал затихает только тогда, когда звучит перевод.
- **Русский дубляж, если он есть**: на YouTube расширение переключает на родную русскую дорожку вместо перевода.
- **Кэш**: готовые переводы хранятся в браузере до 7 дней, повторный просмотр не требует новых запросов.

## Установка

### Расширение для Chrome

1. Скачайте актуальный архив (например `Nova_Video_Translate_v0.3.22.zip`) из [релиза](https://github.com/confeden/Nova-Video-Translate/releases).
2. Распакуйте архив в удобное место.
3. Перейдите в `chrome://extensions/`.
4. Включите **«Режим разработчика»** (Developer mode).
5. Нажмите **«Загрузить распакованное расширение»** (Load unpacked) и выберите распакованную папку.
6. Откройте видео и нажмите зелёную кнопку NVT в панели управления плеера или значок расширения.

Чтобы обновить расширение, замените файлы в папке и нажмите «Обновить» на странице `chrome://extensions/`.

### Скрипт для Tampermonkey (экспериментально)

1. Установите [Tampermonkey](https://www.tampermonkey.net/).
2. Откройте файл `Nova_Video_Translate.user.js` из релиза и подтвердите установку.

### Сборка из исходников

Нужен Node.js 20+.

```
npm install
npm run build
```

Готовое расширение появится в `apps/extension/.output/chrome-mv3`, скрипт — в `apps/userscript/dist`.

## Настройки

- **Живые голоса**: в списке источников у пункта «Яндекс — живые голоса» нажмите «Войти в Яндекс». Пароль расширению не передаётся — вход проходит на сайте Яндекса.
- **Groq**: у пункта Groq нажмите «Получить ключ», создайте бесплатный ключ и вставьте его в поле.
- **Нейросеть Chrome**: если модели ещё не скачаны, в одноимённом разделе появится кнопка «Скачать модели Chrome».
- **Диагностика**: кнопка «Сохранить отчёт на рабочий стол» создаёт текстовый файл без ключей и токенов.

## Безопасность и конфиденциальность

- Ключи и токены хранятся только в вашем браузере и никуда не отправляются, кроме сервисов, которым они принадлежат (Яндекс, Groq).
- Расширению не нужны ваши пароли. Вход в Яндекс проходит по протоколу OAuth на сайте Яндекса.
- Отчёт диагностики не содержит ключей и токенов.
- Модели локальных голосов и нейросети Chrome скачиваются только после вашего нажатия на кнопку.
